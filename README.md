## English 🇬🇧
> [!IMPORTANT]
> This is the Undertale Yellow branch, for the DELTARUNE port, see the [main](https://github.com/pugdev3/deltaport/tree/main) branch.

This a unofficial Linux port of fan game **[Undertale: Yellow](https://gamejolt.com/games/UndertaleYellow/136925)** by [Team Undertale Yellow](https://gamejolt.com/@TeamUTY)

This uses the existing deltaport stack for DELTARUNE, but very simplified for this project

I'm aware there are other Linux ports for this game, but I don't like how they are made, requiring you to install external dependencies.

This already includes everything necessary to run the game, being as simple as running the .sh file

To use it, download the **[latest release here.](https://github.com/pugdev3/deltaport/releases/download/v0.06/ut-yellow-linux.tar.gz)**

Extract the game, then run `./UndertaleYellow.sh` on the folder to run the game :D

Your save files should be located at `~/.config/Undertale_Yellow`

Tradução feita pela [TEIARRUMA](https://github.com/teiarruma/undertale-yellow-ptbr), projeto não afiliado com eles
