## English 🇬🇧
> [!IMPORTANT]
> This is the Undertale: Kindred Spirits branch, for the DELTARUNE port, see the [main](https://github.com/pugdev3/deltaport/tree/main) branch.

This a unofficial Linux port of fan game **[Undertale: Kindred Spirits](https://gamejolt.com/games/undertale-kindred-spirits/145217)** by [purrsum](https://gamejolt.com/@PurrSum)

This uses the existing deltaport stack for DELTARUNE, but very simplified for this project

To use it, download the **[latest release here.](https://github.com/pugdev3/deltaport/releases/download/v0.06/ut-kindred-spirits-linux.tar.gz)**

Extract the game, then run `./UTKindredSpirits.sh` on the folder to run the game :D

Your save files should be located at `~/.config/Undertale_Kindred_Spirits_Prologue`

## Português 🇧🇷
> **NOTA**: Esse é o port para Undertale: Kindred Spirits, para o port de DELTARUNE, veja a branch [pt-br](https://github.com/pugdev3/deltaport/tree/pt-br).

Esse aqui é um port não oficial do **[Undertale: Kindred Spirits](https://gamejolt.com/games/undertale-kindred-spirits/145217)** por [purrsum](https://gamejolt.com/@PurrSum)

O projeto usa os scripts do deltaport feitos pro DELTARUNE, mas extremamente simplificados pra este projeto.

Para jogar, baixe a **[úlitma versão aqui.](https://github.com/pugdev3/deltaport/releases/download/v0.06/ut-kindred-spirits-linux.tar.gz)**

Extraia o jogo, e rode `./UTKindredSpirits.sh` íncluido na pasta pra rodar o jogo :D

Se você quer jogar em Português, então passe pela intro, selecione `Config -> Language` e selecione português :3

Seus saves devem estar localizados em `~/.config/Undertale_Kindred_Spirits_Prologue`

Tradução feita pela [TEIARRUMA](https://github.com/teiarruma/undertale-kindred-spirits-ptbr), projeto não afiliado com eles
